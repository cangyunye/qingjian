## 问字

未输入拼音时输入 `?`（中文模式下也可用问字键 `u`），再用拼音输入问题：

- `?sangemushishenmezi`（三个木是什么字）
- `?mumumu`（报部件）
- `?faguoshoudu`（短事实问答）

停顿后云端返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。`?` 在中英文模式下均可用。
输入 `?` 之后接的不是字母时，它还原为普通问号输出（中文模式全角、英文模式半角）：
`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

未打开云联想时同样可进入问字，但不会得到答案，`Enter` 输出原文。

## 翻译选中的文字

在应用中选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）：

- 选区以汉字为主时译为学习语言；假名或拉丁字母不少于汉字时译回中文。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选区；`Esc` 保留原文；其他键放弃翻译并正常交给应用。

云联想关闭、密码框、应用不支持读取选区（部分 Electron 应用）时，快捷键原样交给应用。快捷键在「偏好设置 → 快捷键」可修改；
Windows 上修改后需切换到其他输入法再切回青简（或重启应用）才生效。

## 朗读译文

打完一句话、上屏之后，按 `Ctrl + Alt + R`（Windows；macOS 暂未提供）：

- 取最近上屏的一条语句，译成学习语言（外文则译回中文），用系统自带语音把**译文**读出来。
- 候选窗口先显示「正在翻译…」，译文返回后边显示边朗读，读完自动消失；朗读期间敲任意键即停止并收起。
- 语音合成在本机完成，不联网发声；译文只发给云服务接口，与「翻译选中文字」一致。
- 系统缺少对应语言的语音包时会提示，可在系统设置的「时间和语言 → 语音」里添加。

需要云联想开着；密码框与私密输入框里敲的内容不参与朗读。连续按快捷键会用新的语句打断上一段朗读。
快捷键在「设置 → 快捷键」改修饰键（字母固定 R）；修改后需切换到其他输入法再切回青简才生效。
